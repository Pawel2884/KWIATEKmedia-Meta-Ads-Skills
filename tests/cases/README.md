# Przypadki testowe

Sześć celowo różnych biznesów. Każdy brief jest napisany tak, jak Paweł realnie by go wpisał:
krótko, bez pełnych danych. Część briefów celowo ma luki (brak dowodów, brak budżetu),
żeby sprawdzić, czy skille pytają tylko o to, co niezbędne, i nie zmyślają liczb.

| Plik | Typ | Co testuje szczególnie |
|---|---|---|
| `01-b2b-flota.md` | B2B | decydent, dłuższy proces, demo, ROI |
| `02-lokalna-fizjoterapia.md` | usługa lokalna | lokalność, polityka Meta "personal attributes" (zdrowie) |
| `03-droga-pompy-ciepla.md` | droga usługa, lead gen | wysoki koszt decyzji, dotacja, jakość leadów |
| `04-ecommerce-krzeslo.md` | produkt / e-commerce | demo produktu, cena, porównanie |
| `05-zaufanie-upadlosc.md` | oferta wymagająca zaufania | wstyd, ryzyko, finanse osobiste, zgodność |
| `06-agencja-kwiatekmedia.md` | usługa B2B (agencja) | przejedzone obietnice branży, wiarygodność |

Liczby i dowody podane w briefach są jedynymi, których skille mogą użyć jako faktów.
Każda inna liczba w reklamie jest traktowana w testach jako potencjalnie zmyślona.
